# Security Policy

## Scope

This repository contains documentation: commands, configuration examples and write-ups for KodeKloud labs. It does not ship software, so there are no supported versions or releases.

## What to Report

Please tell me if you find any of the following:

- **Exposed secrets:** a real password, token, private key or other credential committed anywhere in the repo or its history.
- **Unsafe instructions:** a command or configuration that could cause data loss or weaken the security of a system in an unexpected way.
- **Personal data** that should not be public.

All lab values (hostnames, users, ports) are sandbox examples. Passwords are intentionally not stored here.

## How to Report

1. **Preferred:** use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.
2. **Otherwise:** open a regular issue that describes the problem **without** including the secret itself, and I will follow up privately.

## What to Expect

This is a personal learning project, so responses are best effort. I will review reports as soon as I can, remove or fix confirmed problems, and credit you if you would like.

## For Contributors

Never commit real credentials. If you commit one by mistake, treat it as compromised: rotate it first, then remove it from the repository history.
